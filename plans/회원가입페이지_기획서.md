# 회원가입 페이지 기획서
### 대상 서비스: 랭카드(LangCard, 가제) — 한국·일본 사용자 대상 외국어 학습 + 커뮤니티 서비스

> 이 문서는 기획 의도, 화면 구성, 카피, 인터랙션, 구현 스펙까지 포함합니다.
> 초보 개발자나 로컬 AI가 이 문서만 읽고도 동일한 결과물을 만들 수 있도록
> 추상적 설명 대신 구체적인 수치·문구·구조를 명시합니다.
> 서비스명(랭카드)은 가제이므로, 실제 확정된 이름으로 전체 치환해서 사용하세요.

---

## 0. 기획 배경 및 목적

| 항목 | 내용 |
|---|---|
| 타겟 사용자 | 한국 사용자(일본어 학습자), 일본 사용자(한국어 학습자) — 양방향 |
| 서비스 컨셉 | 플래시카드 + 한자/문자 획순 학습 + 학습 커뮤니티 |
| 가입 페이지의 역할 | "이탈 없이, 재미있게, 학습 목표까지 자연스럽게 이어지는 첫 경험" |
| 핵심 원칙 | ① 입력 항목 최소화 ② 소셜 로그인 우선 노출 ③ 가입 자체를 첫 학습 경험처럼 설계 |

가입 페이지는 단순 "계정 생성"이 아니라, **사용자가 처음으로 서비스의 톤앤매너와 학습 방식을 체험하는 온보딩의 일부**로 설계합니다.

---

## 1. 타겟 시장 특성 반영 사항

한국과 일본은 로그인/개인정보 관행이 다르므로, 이를 UI 우선순위에 반영합니다.

| 구분 | 한국 사용자 | 일본 사용자 |
|---|---|---|
| 선호 소셜 로그인 | 카카오 > 구글 > 애플 | LINE > 구글 > 애플 |
| 이메일 가입에 대한 태도 | 보조 수단으로 인식 | 여전히 신뢰도 높음, 필수 옵션으로 유지 |
| 개인정보 민감도 | 보통 (본인인증 관례적) | 매우 높음 (필요 최소 항목만 요구해야 이탈 낮음) |
| 문구 톤 | 친근하고 캐주얼 | 정중하고 명확함 (경어체 사용) |

**설계 반영:** 소셜 로그인 버튼은 접속 지역(브라우저 언어/타임존)을 감지해 우선순위를 자동으로 바꿉니다.
- 한국어 브라우저 감지 시 버튼 순서: 카카오 → 구글 → 애플 → 이메일
- 일본어 브라우저 감지 시 버튼 순서: LINE → 구글 → 애플 → 이메일

## 2. 디자인 컨셉 & 톤앤매너

### 무드
"공부방"이 아니라 "친구와 함께 성장하는 공간" — 딱딱한 학습지 느낌을 피하고, 성장/새싹 이미지를 활용한 따뜻한 톤.

### 컬러 팔레트 (CSS 변수로 바로 사용 가능)
```css
:root {
  --color-bg: #FAF7F2;        /* 종이 질감의 아이보리 배경 */
  --color-primary: #3E7C59;   /* 새싹/성장 그린 - 주요 버튼 */
  --color-primary-hover: #2F6146;
  --color-accent: #E8A33D;    /* 리워드/포인트 강조용 웜 옐로우 */
  --color-text: #1C1C1C;
  --color-text-sub: #6B6459;
  --color-line: #DDD6CB;
  --color-error: #C0392B;
  --color-kakao: #FEE500;
  --color-line-app: #06C755;
}
```

### 타이포그래피
- 한국어: `'Pretendard', 'Noto Sans KR', sans-serif`
- 일본어: `'Noto Sans JP', 'Hiragino Kaku Gothic ProN', sans-serif`
- 제목: 20~24px / bold
- 본문: 14~15px / regular
- 버튼 텍스트: 15px / medium

### 반드시 피할 것
- 각진 회색 박스형 전통 "회원가입 폼" 느낌
- 한 화면에 5개 이상의 입력창이 동시에 보이는 구성 (부담감 유발 → 이탈 원인)

## 3. 가입 플로우 (전체 단계 설계)

한 화면에 모든 걸 몰아넣지 않고, **단계형(step-by-step) 구조**로 나눕니다.
각 단계 사이에는 상단에 진행률 바(progress bar)를 노출해 "얼마 안 남았다"는 느낌을 줍니다.

```
[진입] → Step 1: 로그인 방식 선택
       → Step 2: 기본 정보 입력 (소셜 선택 시 자동 생략)
       → Step 3: 학습 언어 & 목표 선택 (재미 요소)
       → Step 4: 약관 동의
       → Step 5: 가입 완료 + 웰컴 리워드 화면
```

전체 5단계, 예상 소요 시간 60초 이내를 목표로 설계합니다.

## 4. 화면별 상세 스펙

### Step 1. 로그인 방식 선택 화면

**레이아웃 (세로 스택, 중앙 정렬, 최대 너비 400px)**

```
┌─────────────────────────────┐
│        [서비스 로고]           │
│                                │
│   "매일 조금씩, 함께 성장해요"    │  ← 헤드카피 (H1, 22px, bold)
│   서브카피 (14px, --color-text-sub)│
│                                │
│  [🟡 카카오로 시작하기]          │  ← 최상단 버튼 (지역 감지 우선순위 1위)
│  [🟢 LINE으로 시작하기]         │  ← (일본어 감지 시 1위로 순서 교체)
│  [⚪ Google로 계속하기]         │
│  [⚫ Apple로 계속하기]          │
│                                │
│  ──────── 또는 ────────        │
│                                │
│  [이메일로 가입하기]  (텍스트 링크)│
│                                │
│  이미 계정이 있으신가요? [로그인] │
└─────────────────────────────┘
```

**버튼 스펙**
- 높이: 48px, border-radius: 8px, 너비: 100%(컨테이너 기준)
- 소셜 버튼은 좌측에 브랜드 아이콘(24x24), 우측 정렬 없이 텍스트 중앙
- 버튼 간 간격: 12px

**마이크로카피 예시**

| 위치 | 한국어 | 일본어 |
|---|---|---|
| 헤드카피 | 매일 조금씩, 함께 성장해요 | 毎日少しずつ、一緒に成長しよう |
| 카카오 버튼 | 카카오로 시작하기 | — (한국어 화면에만 노출) |
| LINE 버튼 | — | LINEではじめる |
| 이메일 링크 | 이메일로 가입하기 | メールアドレスで登録 |

---

### Step 2. 기본 정보 입력 화면 (이메일 가입 선택 시에만 노출)

소셜 로그인을 선택하면 이 단계는 자동 스킵되고 Step 3으로 바로 이동합니다(입력 최소화 원칙).

**입력 항목 (딱 4개만)**
1. 닉네임 (실명 대신 — 커뮤니티 활동명이므로 부담 감소)
2. 이메일
3. 비밀번호 (8자 이상, 입력 중 실시간 강도 표시)
4. 비밀번호 확인

**UX 디테일**
- 각 입력창 하단에 실시간 유효성 메시지 표시 (빨간 텍스트, 12px)
- 닉네임 중복 확인은 입력 멈춘 후 0.5초 뒤 자동 체크(디바운스), 별도 "중복확인" 버튼 없이 처리
- 비밀번호 입력창 우측에 눈 아이콘(👁) 토글로 표시/숨김

**예시 플레이스홀더 문구**

| 필드 | 한국어 | 일본어 |
|---|---|---|
| 닉네임 | 커뮤니티에서 사용할 이름 | コミュニティで使う名前 |
| 이메일 | example@email.com | example@email.com |
| 비밀번호 | 8자 이상 입력해주세요 | 8文字以上で入力してください |

---

### Step 3. 학습 언어 & 목표 선택 (재미 요소 핵심 단계)

이 단계가 **"가입을 재미있게" 만드는 핵심**입니다. 폼이 아니라 카드 선택형 UI로 구성합니다.

**3-1. 학습 언어 선택**
```
"어떤 언어를 배우고 싶으세요?"

[🇯🇵 일본어]   [🇰🇷 한국어]   [🇬🇧 영어(추후 지원 예정)]
```
- 카드형 버튼(정사각형에 가까운 비율, 120x120px), 국기 이모지 + 텍스트
- 선택 시 카드 테두리가 --color-primary로 강조되고 살짝 확대(scale 1.05) 애니메이션

**3-2. 학습 목표 선택 (복수 선택 가능, 태그형 버튼)**
```
"학습 목표를 골라주세요 (복수 선택 가능)"

[일드/애니 자막 없이 보기]  [한자 정복하기]  [자격증/시험 대비]
[여행 회화]  [커뮤니티에서 친구 만들기]
```
- 선택된 태그는 --color-accent 배경으로 채워짐
- 이 데이터는 이후 대시보드의 추천 콘텐츠 개인화에 사용 (내부 로직 연동 필요)

**3-3. 현재 레벨 간단 체크 (선택, 건너뛰기 가능)**
```
"지금 실력은 어느 정도인가요? (선택)"
○ 이제 시작해요   ○ 기초는 알아요   ○ 어느 정도 해요   [건너뛰기]
```

> 이 단계는 부담 없이 "게임 캐릭터 만들기"처럼 느껴지도록 설계하는 것이 핵심입니다.
> 진행률 바가 이 단계에서 60% → 80%로 올라가는 것을 시각적으로 보여줍니다.

---

### Step 4. 약관 동의

**구성 원칙:** 법적으로 필요한 내용이지만 가장 지루한 단계이므로, 최대한 짧고 명확하게.

```
[✔] (필수) 이용약관 및 개인정보처리방침에 동의합니다   [보기]
[ ] (선택) 이벤트 및 학습 팁 알림 받기
              [다음 →]
```
- 필수 항목 체크 전에는 "다음" 버튼 비활성화(회색, 클릭 불가)
- 일본 사용자 대상 화면에는 개인정보처리방침 링크를 더 눈에 띄게(밑줄 처리) — 민감도 반영

---

### Step 5. 가입 완료 + 웰컴 리워드 화면

가입 직후 이탈을 막고 첫 학습으로 자연스럽게 유도하는 화면입니다.

```
┌─────────────────────────────┐
│      🌱 (새싹 성장 일러스트)     │
│                                │
│   "환영해요, {닉네임}님!"         │
│   첫 학습 카드 10개를 선물로 드려요 │
│                                │
│   [첫 학습 시작하기 →]           │  ← 대시보드가 아닌 "플래시카드 1세트"로 직행
└─────────────────────────────┘
```

- 가입 완료와 동시에 실제 보상(예: 무료 플래시카드 세트, 스타터 뱃지)을 즉시 지급 → 성취감 제공
- "대시보드로 이동" 대신 "첫 학습 시작하기"로 CTA를 걸어 즉시 행동 유도 (가입-첫사용 간극 최소화)

---

## 5. 반응형 / 접근성 고려사항

- 모바일 기준(360px~430px)을 기본으로 설계하고, 데스크톱은 중앙 400~480px 카드로 확장
- 모든 버튼 터치 영역 최소 44x44px 확보
- 입력 오류 메시지는 색상뿐 아니라 아이콘(⚠)도 함께 표시 (색맹 사용자 고려)
- 한/일 혼용 폰트 렌더링 깨짐 방지를 위해 `lang` 속성을 문서 및 언어 전환 시마다 갱신

## 6. 구현 스켈레톤 (로컬 AI/초보 개발자용 시작 코드)

아래는 Step 1 화면 기준의 최소 뼈대입니다. 이 구조를 기준으로 Step 2~5를 같은 패턴으로 이어 붙이면 됩니다.

**다음 단계로 이어붙이는 방법**
- Step 2~5는 위와 동일한 `.signup-card` 구조를 재사용하고, 내용만 교체
- 화면 전환은 별도 페이지 이동 없이 하나의 HTML 안에서 `display:none/block` 토글로 처리하는 것을 권장 (이탈률 감소, 새로고침 시 진행 상태 유지 이슈 회피)
- 진행률 바의 `width` 값만 단계별로 20% → 40% → 60% → 80% → 100%로 JS에서 갱신
